# 跨模型复现实验：切块 + 放大（2026-09-29）

> 目的：把 deepseek-v4.1-flash 上的"切块 + 放大"结论拿到**另一个模型**上验证，
> 并顺带把"关键臂重复"这条欠账补上一次。
> 本轮模型：**`ark-coding-plan-av/doubao-seed-evolving`**（用户指定先测这个）。
> 判定用语沿用本仓：✅ 成立 / ❌ 否定 / ⚠️ 部分成立 / ❓ 未测。

---

## 0. 一句话

**"插值放大"在第二个模型上的收益远小于第一个：召回增益从 +8.3 点掉到 −0.1 点（噪声内），
而精确率增益稳定复现（两个模型都到 100%）。**

按量分开说：

| 量 | deepseek 1×→1.633× | doubao 1×→1.633× | 是否跨模型成立 |
|---|---|---|---|
| 召回 | 86.1% → 94.4%（**+8.3**） | 94.5% → 94.4%（**−0.1**） | ❌ 幅度不成立 |
| 精确率 | 91.2% → 100%（**+8.8**） | 94.3/97.2% → **100%/100%**（**+4.2**） | ✅ 成立（5/5 臂零误报） |

（注：doubao 的 1× 基线本身两次重复就差 2.9 点，所以 `+4.2` 是**均值差**，
真正稳的是"1.633× 两次都精确到 100% 且零误报"这个**模式**，不是那个点数。）

⇒ **放大不是"再加一截"的普适增量，而是"把模型在原生尺寸下丢掉的那部分找回来"。
补回多少，取决于该模型在 1× 丢了多少。**
doubao 在 1× 已接近自身上限（94.5%），所以几乎无处可补。

**而且精确率增益的成分要打折**：放大主要是把被切碎片从"硬猜错"变成"如实弃权"（详见 §4），
**不能把它当成"识别能力提升"来计价。**

## 1. 设计（三处比原实验更严的地方）

| 项 | 本轮做法 | 为什么 |
|---|---|---|
| 臂 | 只发瓦片，**不发全图** | 原 F 臂里 F 从未报全图、E 报了，是个不对称；去掉全图即消除 |
| 隔离 | 每臂**独立目录**、文件名统一为 `img01..img16` | 原瓦片名带 `x960_y1620_w960_h540`，会泄露"有网格"；统一命名后三档交付**在文件名上不可区分** |
| 提示词 | 除目录路径外**逐字相同**，不含尺度、数量、顺序 | 尺度映射只存在于 `make-runs.ps1` / `score-xmodel.mjs`，从不进读图者上下文 |

| 档 | 交付尺寸 | 放大 | 臂 | 说明 |

## 4. 判定

### ✅ 成立（强）：放大消除误报，两个模型一致

1.000× 下两个模型都产生误报（deepseek 3 个、doubao 每臂 1 个）；
1.633× 下**5/5 臂误报为 0、精确率 100%**。
方向一致、机制可解释（字高不足导致的字形误读，放大后消失）。

### ✅ 成立（强）：倍率的**方向**跨模型复现，倍率的**幅度**不是常数

- **方向**：两个模型都是 1.633× ≥ 1.000×。
- **幅度**：deepseek 召回 +8.3 点，doubao −0.1 点（在噪声内，见 §5）。

⇒ **H\* 是模型专属常数这一条得到支持**，而且比预期更极端：
doubao 在 1× 就已经接近自己的上限，放大几乎无处可补。

### ❌ 否定（强）：3× 没有额外收益

r5（2880×1620，3.000×）与 r2/r4（1568×882，1.633×）**逐项相同**：
召回 94.4%、精确率 100%、同样漏 X6R M6F。
**像素再翻 3.4 倍，识别不再改善。**

⇒ **H\* ≤ 1.633。** "放大到接口上限"当前恰好落在一个足够的位置，
但**不是因为它是最优，而是因为它已越过最优**——超出部分只是白付 token。

### ⚠️ 一个意外的分离：放大改善**识别**，不改善**定位**

r5 的定位误差中位 **2.0px**、最大 3.7px，是五臂里最好的；
但它的召回/精确与 1.633× 完全相同。

⇒ **识别与定位是两个可分离的量，且对交付尺寸的响应不同。**
定位随尺寸单调变好（2.0px @3× < 2.4px @1.633×），识别在 1.633× 就饱和。
**建议评分器把这两个量分开报告——原报告把它们混在一张表里。**

### ⚠️ 被切标签：放大没有救它们，而是让模型**改口**

逐臂精确统计（按真值码精确匹配，不用模糊正则）：

| 标签 | 1× （doubao 2 臂 + deepseek E） | 放大（doubao 3 臂 + deepseek F） |
|---|---|---|
| **M6F** | 读出 **1/3**（r3）｜r1 报 UNCERTAIN｜E 未提及 | 读出 **0/4**；r2/r4/r5 **全部报 UNCERTAIN**（"third character cut off"）｜F 未提及 |
| **X6R** | 读出 **0/3** | 读出 **0/4** |

**两条都不支持"放大能救被切标签"**（我起初据 r3 的孤例这样写过，被全表推翻）。真实模式是：

- **X6R**：**8/8 次运行全部未读出**。它横跨 x=960 接缝，在 16 块瓦片里**永远只有左半**，
  左半边信息从未被任何一块交付 ⇒ **放大救不了它，只有重叠能救。**
- **M6F**：放大到 1.633×/3× 后，三个臂**都把它认成了"残缺的 M6F"**（`"only M6 visible"`），
  也就是**从"漏掉/猜错"变成"如实弃权"**。它没有被读出，但它**不再产生误报**。

### ⚠️ 由此得到一条比原结论更准的机制：放大的主要收益是"学会弃权"

把 §4 的三个判定串起来看，机制是自洽的：

```
1×        ：被切碎片被编码成一个"没被切的最近字形" → 硬猜 → 误报（r1/r3 都猜 K6R）
1.633×/3× ：同一碎片被编码成"这是残缺的"          → 弃权 → UNCERTAIN
结果       ：误报 1→0、精确率 95.8%→100%，而召回几乎不动（94.5%→94.4%）
```

⇒ **放大的账面收益（精确率 +4.2、误报 −1）里，主要成分不是"读得更准"，
而是"知道自己看不清"。** 这是好事——UNCERTAIN 是有效信号，误报是污染——
但它意味着**不能把"精确率提升"当成"识别能力提升"来计价**。

⇒ 于是原报告 H9 的措辞要再收紧一次：
**碎片化不是"剩余瓶颈"，而是"不可消除的损失"与"可避免的污染"两部分**——
X6R 属于前者（只能靠重叠），M6F 属于后者（放大可把它从污染变成弃权）。

### ❓ 未测：H\* 的具体位置

三个点（1.000 / 1.633 / 3.000）只能断定 **H\* ≤ 1.633**，
不能排除 H\* 在 1.0 与 1.633 之间（此时 1× 那条腿的均值守恒会掩盖拐点，
因为它是两个相反效应的和）。需要细扫 1.2/1.3/1.4/1.5 才能定位。

### ❓ 未测（本轮新增假设，需独立判定）：放大是否**抵消**了瓦片边缘的随机裁切

**现象**：1× 的两臂共产生 2 个误报，且**都是被切标签被读成了另一个码**：

```
r1: K6R (真值 X6R)   ← K 不在真值表里
r3: K6R (真值 X6R)   ← 同上
```

两个**独立**子代理看同一块被切的碎片，都读成 `K6R`。
而放大臂在同样位置报的是 UNCERTAIN，没有硬猜。

**假设**：字高不足时，被切碎片的残笔更容易被编码成"没被切的另一个字形"
（K 与 X 的左半在低分辨率下近似）；放大让模型看清"这是残缺的"，
于是它**转向如实报 UNCERTAIN 而不是投一个码**。

**为什么值得单列**：这条预测的是**误报率**（可判定、可复现），
与放大改善召回是两件事，而且它解释了 §4 的精确率增益里有一部分来自"学会弃权"。

⚠️ **本轮不做**：要判定它必须改素材或改评分口径，会污染正在跑的批次。
**下一轮第一件事**，且它比"细扫 H\*"更便宜（复用现有素材即可，只需新增"被切碎片"标注列）。

## 5. 噪声与强度声明

- **n=36**，1 SE ≈ 6.7 点（p≈0.8）。**所有召回差异都 < 1 SE，单独不可解释。**
- 但**精确率 91.2%→100% 与误报 3→0 是模式级一致的**（5/5 臂零误报），
  比单点召回差异更可信——按原报告的口径，这属于"模式强、分数弱"。
- **doubao 上：1× 3 次、1.633× 2 次、3× 1 次**，仍不足以给区间。
  本轮的重复只够看出一件事：**同条件的臂间方差与臂间差异同量级**——
  同为 1× 的 r1 与 r3 召回差 5.5 点（91.7 vs 97.2），
  同为 1.633× 的 r2 与 r4 定位误差差 5.3 倍（12.7px vs 2.4px）。
  ⇒ **单次运行的召回数字不可当结论用**，本轮的可靠结论只有"模式级"的那两条（零误报、X6R 恒漏）。
- **只测了两个模型**，且都是中国厂商的模型；结论不能外推到 Claude / Qwen 系
  （本仓已有记录：坐标格式偏好按模型系不同）。

## 6. 对工程假设的修正

原假设写的是：

> 先切块把注意力窗口内目标数压下来，再用放大把交付字高推回模型偏好尺寸 H\*。

本轮修正为：

> **切块是必要条件（跨模型一致）。放大是"补差"条件，不是"增量"条件——
> 它补的是该模型在原生交付尺寸下丢掉的那部分；补回多少取决于该模型在 1× 损失了多少。
> H\* 是模型专属常数，且"放到接口上限"已经越过 H\*（doubao 上 1.633× 与 3× 逐项相同）。
> 放大的账面收益里有一部分不是"读得更准"而是"学会弃权"——计价时必须分开。
> 两条剩余损失必须分开治：被切掉一半的（X6R）只能靠重叠，8/8 次运行无一读出；
> 切得不够好的（M6F）可由放大变成如实弃权，从而不再污染精确率。**
>
> 另一条本轮固化的纪律：**被切碎片上的"硬猜"是可测量的**——两个独立子代理都把 X6R 的
> 左半碎片读成 `K6R`（K 不在真值表内，属误报）。"半截码被报成一个完整码"应单独计一列，
> 否则它只会被算作普通误报，看不出机制。
